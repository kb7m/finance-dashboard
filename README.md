# MY FINANCE — v1.2

既存のv1.1を更新したPWA版です。データ保存キー `my-finance-v1` は変更していません。

## 起動

`index.html` があるフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開きます。VS Code Live Serverでも利用可能です。

## 更新内容

- 5画面ナビゲーション（ダッシュボード、取引、貯金目標、分析、設定）
- 取引追加・編集モーダル、削除
- 月・取引種類での絞り込み
- 支出カテゴリの分析
- JSONバックアップ・復元
- レスポンシブデザイン

## 注意

データはブラウザのLocalStorageに保存されます。同じオリジン（例 `127.0.0.1:5500`）で開くと以前のデータを引き継げます。`localhost` と `127.0.0.1`、またはポートが異なる場合は別データです。既存フォルダを上書きする前にバックアップしてください。貯金積立は収支と連動しません。

PWAのオフライン動作はService Workerが制御します。更新が反映されない場合は再読み込みしてください。
