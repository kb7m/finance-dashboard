# Finance Dashboard v1.3

Ver.1.2をベースに更新。収入・支出・貯金の3カード。

- 「＋取引を追加」→「種類：貯金」で手動登録。編集・削除・月別絞り込み・グラフ対応。
- 貯金は収入−支出の自動計算ではありません。貯金の記録は支出として計上されません。
- 貯金目標の積立は従来どおり独立しており、貯金カードには自動反映されません（二重計上を避けるため）。
- LocalStorage キー `my-finance-v1` を維持し、旧取引・目標をそのまま読み込みます。
- バックアップJSONはv1.2からの形式を読み込めます。
- 同じオリジン（プロトコル・ホスト・ポート）のブラウザで開いてください。公開先GitHub Pagesはlocalhostと別保存領域です。
- 初回アップデート前に設定画面からJSONバックアップ推奨。
- GitHub Pagesで更新する場合は同名ファイルを置換してcommit/push。Service Workerキャッシュ名もv1.3に変更済み。
